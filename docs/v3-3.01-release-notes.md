## User-facing changes and migration

The v3 engine separates parsing/evaluation and builtin implementation,
with selected corrections to JSON type comparisons, numeric arithmetic,
null/empty streams, ordinary field paths and assignment/update behavior.
The [migration guide](v3-migration.md), [compatibility matrix](jq-compatibility.md),
and [semantic differences](jq-semantics-differences.md) define the exact
supported scope and retained v2 differences. Complete jq parity, compiled
query APIs and additional platform support are not promised.

Library callers continue to collect `run_query` results in a Perl list.
Null is one `undef`; empty output has no values. Objects/arrays remain
references, JSON booleans retain their representation, and structured
input/parse/evaluation errors retain their categories. The
[Library contract](library-contract.md) and [CLI contract](cli-contract.md)
remain the integration references.
